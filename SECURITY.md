# Security Policy

## Supported usage

VECTPHISH is intended as an analyst-support tool for phishing campaign correlation and enrichment.

## Security model

- Local execution
- Local SQLite storage
- No telemetry collection
- No runtime internet requirement after local models are installed
- Optional local Ollama LLM execution

## Reporting a vulnerability

Please report security issues privately to the maintainers before public disclosure.

Do not submit real phishing datasets, credentials, personal data, or sensitive internal logs in public issues.
